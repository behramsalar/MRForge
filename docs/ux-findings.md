# UX findings (lab user test)

Filled in by the observer during and after each test (see `docs/ux-test-script.md` for the method and the template). One block per tester. Do not tidy or interpret during the session; write what happened.

## Tester 1 (comments relayed by the project owner, 2026-11-01; Linux computer; not a timed observation)

- Import is flawed: errors when trying to import NIfTI files. Cannot import from several ZIP files that are in the selected folder; importing a single ZIP works, but doing them one by one is tedious.
- When starting processing, the "Change settings" option is buried; the layout of the popup where one selects what to do could be better.
- There is no way to do only functional processing without doing anatomical processing in the same app.
- In the artifact rejection window, selecting components and loading them in the viewer is a bit slow on Linux compared to the owner's computer.
